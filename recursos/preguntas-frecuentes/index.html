    Preguntas Frecuentes ❓¶

    Autenticación y Acceso¶

    ¿Cómo obtengo mi API Key?
    1. Inicia sesión en tu panel de desarrollador
    2. Ve a "Claves API"
    3. Haz clic en "Generar nueva clave"
    4. ¡Cópiala inmediatamente! (solo se muestra una vez)

    Warning

    Si pierdes tu clave, deberás generar una nueva y actualizar todas tus integraciones.

    Uso de la API¶

    ¿Cómo filtro por modelos disponibles?

    Usa el parámetro disponible=true: 

    GET /v1/modelos?disponible=true&marca=Rolex

    Problemas Comunes¶

    Error 429: Too Many Requests

    Solución: - Espera 1-2 minutos - Implementa retry con backoff exponencial: 

    import time
from tenacity import retry, stop_after_attempt, wait_exponential

@retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=1))
def get_modelos():
    return api.get_modelos()

    Modelos que no aparecen en búsquedas

    Causas posibles: 1. El modelo está marcado como "edición limitada" 2. Filtros demasiado restrictivos 3. Necesitas permisos "premium"

    Soporte Técnico¶

    ¿Dónde reporto bugs?

    Abre un issue en nuestro GitHub con: 1. Endpoint usado 2. Código de error 3. Timestamp (UTC) 4. Tu request ID (encabezado X-Request-ID)
